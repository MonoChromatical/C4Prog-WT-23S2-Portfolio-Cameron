# Web Technologies Portfolio

This project is a portfolio website created for the Certificate IV in Information Technology Web Technologies assessment. The purpose of the site is to display and showcase current and future coding work through a responsive multi-page portfolio.

## Assessment Overview

To complete this assessment, the portfolio will be designed and developed with several pages, including a home page layout. The project will be version controlled as development progresses.

The assessment includes:

- Initial project setup
- Version control
- Wireframe designs
- Use of imagery
- HTML, CSS, and JavaScript
- Use of TailwindCSS
- Browser testing in at least two browsers with different rendering engines
- Compressing and submitting the completed work

## Site Requirements

The site must:

- Be fully responsive
- Contain all required elements
- Use a mobile-first CSS design
- Use semantic HTML elements in Tailwind components instead of relying on generic `div` elements

## Planned Website Pages

- `index.html` - home page
- `contact.html` - contact page
- `about.html` - about page
- `resume.html` - resume page
- `projects.html` - projects page
- `mywork.html` - sample projects page
